# 💰 Expense Tracker

A simple Android expense tracking application built with **Kotlin** and **Jetpack Compose**.

The app helps users record daily expenses, organize them by category, and keep track of total spending.

## ✨ Features

- ➕ Add new expenses
- 💰 Enter expense amount
- 🏷️ Categorize expenses
- 📅 Track expense dates
- 📊 View total spending
- 🗑️ Delete expenses
- 💾 Local data persistence
- 🎨 Custom application icon
